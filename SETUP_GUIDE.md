## 🔄 Complete Workflow

1. **User visits website** → Clicks "Submit Your Event" button
2. **User fills out Google Form** → Submits event details
3. **Form submission triggers script** → Creates UID, copies to Pending sheet
4. **Script sends email** → You receive approval email with approve/reject links
5. **You click approve** → Event moves from Pending to Events sheet
6. **Website updates** → Approved event appears on the website (auto-refreshes when users load the page)

## 🐛 Troubleshooting

### Events not showing on website?
- Check that events exist in the "Events" sheet (not Pending)
- Verify the Events sheet has the correct column headers
- Check browser console for errors (F12)
- Make sure the event date is today or in the future

### Not receiving approval emails?
- Verify the trigger is set up in Apps Script
- Check spam folder
- Verify email address in script is correct

### Approve/Reject links not working?
- Make sure the Web App is deployed in Apps Script
- Verify the WEBAPP_URL in the script is correct
- Redeploy the Web App if needed (Apps Script → Deploy → New deployment)
